# UTILORA project rules

- Treat current repository files and README as authoritative; inspect HEAD before relying on prior notes.
- Keep the visual identity warm white, stone gray, and orange. Do not introduce green or purple.
- Preserve all eight locales: en, ar, fr, es, pt, hi, zh, bn. Arabic must be RTL.
- Keep interfaces responsive, readable, accessible, and fast. Avoid heavy glass effects and excessive animation.
- Make no unsupported claim about an engine, file processing, privacy, analytics, SEO, or deployment.
- Preserve browser-local processing for local tools unless an explicitly reviewed architecture change says otherwise.
- Do not expose secrets, private user data, uploaded files, or raw visitor-level analytics.
- Use isolated branches and small, reviewable changes. Never commit, push, merge, deploy, or alter DNS from an implementation task.
