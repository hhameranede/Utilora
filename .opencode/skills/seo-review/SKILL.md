# SEO review

Verify the actual built HTML, route output, sitemap, robots directives, status codes, canonicals, hreflang, metadata, internal links, and indexability. Confirm hreflang sets are reciprocal and that each locale URL returns the intended language and direction.

Only recommend indexable pages with substantial, accurate, unique user value. Keep unsupported or preview-only tools out of indexable sitemaps. Separate technical observations from ranking speculation. Never invent search metrics or guarantee ranking outcomes.
