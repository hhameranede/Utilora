## Quality and safety rules

- External skills are pinned to immutable upstream Git commit SHAs in `.opencode/skills/manifest.json`.
- Each external skill records its source repository, exact source path, copyright owner, and SPDX-style licence identifier.
- Third-party instructions are subordinate to UTILORA's agent definitions and repository policies. The retained upstream skill files include a UTILORA scope and safety override.
- Skills do not grant additional shell, file-editing, MCP, GitHub, Cloudflare, deployment, or production privileges.
- The project uses React 19, TypeScript, Vite 8, Tailwind CSS v4, and Cloudflare Pages. Skills requiring Next.js, Vercel deployment credentials, React Native, Swift, browser MCP services not configured here, or unrelated production operations were excluded.
- All agents deny unassigned skills by default. Their explicit allow-lists are tested against the manifest in CI.
